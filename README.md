<details>
  <summary><strong>온디바이스 지식그래프 기반 AI 지식 관리 앱 "BrainTrace" <a href="https://github.com/HS-MUMU/BrainTrace_OnDeviceAi?tab=readme-ov-file">MuMu</a></strong></summary>
  <br/>
  <img src="https://github.com/user-attachments/assets/3c98fd2c-b38e-4ede-9704-d518111129e1" width="750" alt="braintrace" />
  <h4>📝 프로젝트 소개</h4>
  <p><strong>BrainTrace</strong>는 PDF, 오디오, 텍스트 등 다양한 문서를 자동 분석해 지식 그래프를 구축하고, 이를 기반으로 문맥 이해형 질문 응답을 제공하는 <strong>온디바이스 AI 솔루션</strong>입니다.<br/>
  외부 전송 없이 로컬에서 처리되며, <strong>출처 기반 응답</strong>으로 신뢰성과 투명성을 동시에 제공합니다.</p>

  <h4>🌟 주요 기능</h4>
  <ul>
    <li><strong>온디바이스 AI:</strong> 외부 전송 없이 완전 로컬 처리, 추가 비용 없이 프라이버시 보장</li>
    <li><strong>출처 기반 응답:</strong> 핵심 노드(출처) 제공으로 신뢰성과 투명성 보장</li>
    <li><strong>Graph-RAG 기반 정밀 추론:</strong> 질문과 유사한 노드 탐색 → 관계 추론 → 구조화된 응답 생성</li>
    <li><strong>자동 문서 업로드 & 지식그래프화:</strong> PDF, 오디오, 텍스트 자동 분석 → 시각화 및 검색</li>
    <li><strong>노드 기반 문서 검색 기능:</strong> 키워드 입력 시 관련 노드 및 문서 유사도 기반 검색</li>
  </ul>
